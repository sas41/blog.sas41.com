# blog.sas41.com

A static personal blog built with Hugo.

## Markdown

Superscript is enabled, including links: `A claim.^[1](https://example.com)^`

Raw HTML is also enabled for trusted author-written content, so HTML such as
`<sup><a href="https://example.com">[1]</a></sup>` can be used directly without
the `html` shortcode.
